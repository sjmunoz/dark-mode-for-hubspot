Features

Small, fast, and stays out of your way.

No settings page and no account. It changes the colors of HubSpot and does nothing else.

One-click toggle

Click the toolbar icon to turn dark mode on or off in all HubSpot tabs at the same time.

Keyboard shortcut

Press Alt Shift D. On a Mac, press ⌥ ⇧ D.

Real image colors

Logos, photos and avatars keep their real colors. Only the interface goes dark.

No white flash

The theme loads before the page draws, so HubSpot opens dark.

Private

It reads no page content and sends nothing. It saves one setting in your browser.

How it works

Two CSS rules.

The extension inverts the page colors and turns the hue back, so blues stay blue. Then it inverts images, video and charts again, so they keep their real colors.

The background becomes dark gray (#1a1a1a), which is easier on the eyes than pure black.

/* dark.css */
html {
  filter: invert(0.9) hue-rotate(180deg);
}

img, video, canvas {
  filter: invert(1) hue-rotate(180deg);
}
Install

Get it in under a minute.

The Chrome Web Store listing is coming soon. Until it is live, install it from source:

ChromeDiaArcEdgeBrave
  1. Download the zip and unzip it.
  2. Open chrome://extensions. In Dia, use the Extensions menu.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.
  5. Open HubSpot. It is dark.
Privacy

Your CRM data stays yours.

A CRM holds customer data. This extension never touches it. You can check the source code yourself.

  • No data collected. No analytics, no tracking, no remote code.
  • One permission. storage, to save the on/off setting.
  • HubSpot app pages only. It runs on app.hubspot.com and the regional app domains.
  • Open source. Read every line on GitHub.
FAQ

Questions

Does it work with my HubSpot region (EU, NA2, AP)?

Yes. It runs on app.hubspot.com, app-eu1, app-na2, app-na3 and app-ap1.

Some parts look wrong. Why?

A few parts do not follow the theme: images inside email previews, avatars that HubSpot draws as a background image, and some chart colors. Please open an issue with a screenshot. Remove customer data from the screenshot first.

How do I change the keyboard shortcut?

Open chrome://extensions/shortcuts and set a new key for Dark Mode for HubSpot.

Is this an official HubSpot product?

No. This is an independent, free project. It is not affiliated with HubSpot, Inc.
